---
title: Built-in Tools
description: Opt in to Claude Code-style file, search, edit, and shell tools.
---

Built-in tools are not enabled by default. For a real working agent, prefer `createAgent({ workspace })`; it gives that agent private workspace tools and adds instructions to report durable deliverables with natural-language paths and verification notes.

```ts
import { createAgent } from "claude-team-agent-sdk";

const agent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-v4-flash",
  workspace: {
    cwd: process.cwd(),
    allowedDirectories: [process.cwd()],
    bashTimeoutMs: 30_000,
  },
});
```

Use `createClaudeCodeTools()` directly when you want manual control over the tool list instead of attaching a workspace identity to the agent.

## Included tools

| Tool | Capability |
| --- | --- |
| `Read` | Read a workspace file, optionally with line offset and limit. |
| `Write` | Write a file and create parent directories. |
| `Edit` | Replace text in an existing file. |
| `LS` | List a directory. |
| `Glob` | Find files by glob pattern. |
| `Grep` | Search file contents by regular expression. |
| `Bash` | Run a shell command with a timeout. |

Always pair file-writing and shell tools with a permission callback in user-facing products.
