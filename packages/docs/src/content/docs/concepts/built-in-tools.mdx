title: Built-in Tools
description: Agent workspace tools and manual Claude Code-style tool construction.
---

`createAgent()` gives each agent private workspace tools by default. If no `workspace` is provided, files are stored under `~/.agent/workspaces/<agent-name>` or `~/.agent/workspaces/agent-<session-id>`.

Pass `workspace` only to override that default location:

```ts
import { createAgent } from "claude-team-agent-sdk";

const agent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  name: "backend",
  model: "deepseek-v4-flash",
  workspace: {
    cwd: process.cwd(),
    allowedDirectories: [process.cwd()],
    bashTimeoutMs: 30_000,
  },
});
```

Use `createClaudeCodeTools()` directly when you want manual control over the tool list outside the default agent workspace setup.

## Included tools

| Tool | Capability |
| --- | --- |
| `Read` | Read a workspace file, optionally with line offset and limit. |
| `Write` | Write a file and create parent directories. |
| `Edit` | Replace text in an existing file. |
| `LS` | List a directory. |
| `Glob` | Find files by glob pattern. |
| `Grep` | Search file contents by regular expression. |
| `Bash` | Run a shell command with a timeout. |

Always pair file-writing and shell tools with a permission callback in user-facing products.
