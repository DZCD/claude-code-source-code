## Install

```bash
npm install agent-lattice zod
```

## Ask a question

The examples use DeepSeek's Anthropic-compatible endpoint.

```ts
import { createAgent } from "agent-lattice";

const agent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-flash",
  maxTokens: 4096,
  requestTimeoutMs: 60_000,
});

for await (const message of agent.query("Say hello in one sentence.")) {
  console.log(message);
}
```

`agent.query()` returns an async iterator of SDK events. Use it when you want to observe the agent as it runs: initialization, assistant messages, streaming deltas, tool calls, tool results, and the final result.

## Choose a model protocol

*Requires 0.31.0 or later.*

DeepSeek thinking compatibility requires 0.32.0 or later.

The default client uses Anthropic Messages. For an endpoint exposing OpenAI
Responses API, inject `createOpenAIResponsesClient()` through `modelClient`:

```ts
import { createBareAgent, createOpenAIResponsesClient } from "agent-lattice";

const responsesAgent = createBareAgent({
  model: "deepseek-flash",
  maxTokens: 4096,
  requestTimeoutMs: 60_000,
  modelClient: createOpenAIResponsesClient({
    apiKey: process.env.DEEPSEEK_API_KEY,
    baseURL: "https://api.deepseek.com",
    reasoningEffort: "low",
  }),
});

const result = await responsesAgent.prompt("What is 2 + 2?");
console.log(result.result);
```

Put Responses credentials and the base URL on the client factory. The agent's
`baseURL` configures only the default Anthropic client. Changing it alone does
not switch protocols. For OpenAI directly, omit the factory's `baseURL`, use
`apiKey: process.env.OPENAI_API_KEY`, and set the agent's `model` from your
application's `OPENAI_MODEL` configuration. Chat Completions-only endpoints
are not supported by either built-in client.

Use [Configuration](/configuration/#openai-responses-api) for both connection
examples and [Provider Compatibility](/reference/provider-compatibility/) for
thinking, structured output, and media limits.

## Return only the final result

`agent.prompt()` runs the same agent loop and resolves with only the final `result` message. It is the easiest API when your application does not need intermediate events.

```ts
const result = await agent.prompt("What is 2+2?");
console.log(result.result);
```

## Send multimodal input

Pass image input as a content block array. Both clients accept URL and base64
images when the provider/model supports them. The Responses adapter rejects
`document`/PDF input; Anthropic document support depends on the provider.
Image understanding does not enable image generation.

```ts
import { readFile } from "node:fs/promises";

// Read an image file owned by your application.
const imageBase64 = (await readFile("./screenshot.png")).toString("base64");
const result = await agent.prompt([
  { type: "text", text: "Summarize this screenshot." },
  {
    type: "image",
    source: {
      type: "base64",
      media_type: "image/png",
      data: imageBase64,
    },
  },
]);

console.log(result.result);
```

## Choose streaming behavior

`query()` and `prompt()` describe how your app consumes SDK output. The `stream` option controls whether the underlying model request uses streaming.

```ts
// Model streaming + SDK event streaming.
for await (const message of agent.query("Write a short haiku.", {
  stream: true,
})) {
  console.log(message);
}
```

```ts
// Non-streaming model request, while still consuming SDK events.
for await (const message of agent.query("Write a short haiku.", {
  stream: false,
})) {
  console.log(message);
}
```

```ts
// Non-streaming model request + final result only.
const result = await agent.prompt("Write a short haiku.", {
  stream: false,
});
```

Use `outputFormat` for schema-constrained JSON output:

```ts
const jsonResult = await agent.prompt("Return JSON only.", {
  outputFormat: "json",
});

const result = await agent.prompt("Return the answer to 2 + 2.", {
  outputFormat: {
    type: "json_schema",
    schema: {
      type: "object",
      properties: {
        answer: { type: "number" },
      },
      required: ["answer"],
      additionalProperties: false,
    },
  },
});
```

When `outputFormat` is set, the SDK sends structured output parameters to the provider and returns the final text unchanged. Parse or validate the returned JSON in your application when you need a typed value.

For an SDK-validated artifact, use `outputSchema` and read `result.structuredResult`.
The SDK injects `submit_output`, validates its arguments, and applies the same
submission lifecycle on both protocols. `outputFormat` requests a provider
format and returns text; it does not replace SDK validation. See
[Structured output](/concepts/agent-loop/#structured-output-with-submit_output).
