---
title: 内置工具
description: Agent workspace 工具和手动 Claude Code 风格工具构造。
---

`createAgent()` 默认会给每个 agent 增加私有 workspace 工具。如果没有传入 `workspace`，文件会存储在 `~/.agent/workspaces/<agent-name>` 或 `~/.agent/workspaces/agent-<session-id>`。

只有需要覆盖默认位置时，才传入 `workspace`：

```ts
import { createAgent } from "claude-team-agent-sdk";

const agent = createAgent({
  apiKey,
  name: "backend",
  model,
  workspace: {
    cwd: process.cwd(),
    allowedDirectories: [process.cwd()],
  },
});
```

当你想绕开默认 agent workspace 设置、手动控制工具列表时，可以直接使用 `createClaudeCodeTools()`。

## 工具列表

| 工具 | 说明 |
| --- | --- |
| `Read` | 读取工作区文件。 |
| `Write` | 写入工作区文件。 |
| `Edit` | 替换已有文件中的文本。 |
| `LS` | 列出目录。 |
| `Glob` | 按 glob 查找文件。 |
| `Grep` | 按正则搜索文件内容。 |
| `Bash` | 在工作区执行 Shell 命令。 |

## 安全边界

这些工具可以读写文件、执行命令，所以生产环境建议配合 `permission`：

```ts
permission: async request => {
  if (request.toolName === "Bash" || request.toolName === "Write") {
    return {
      behavior: "deny",
      message: "This host did not approve shell or write access.",
    };
  }
  return { behavior: "allow" };
}
```

`allowedDirectories` 会限制文件工具可访问的目录，但它不能替代宿主应用自己的权限策略。
