## DeepSeek

DeepSeek 提供 Anthropic 兼容接口，所以只需要配置 `baseURL` 并使用 DeepSeek 模型名。

```ts
import { createAgent } from "agent-lattice";

const agent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-flash",
  systemPrompt: "你是一个简洁的工程助手。",
  maxTokens: 16384,
  maxTurns: 50,
});
```

## Anthropic

直接使用 Anthropic 时可以省略 `baseURL`：

```ts
const agent = createAgent({
  apiKey: process.env.ANTHROPIC_API_KEY,
  model: "claude-sonnet-4-6",
  systemPrompt: "你是一个简洁的工程助手。",
});
```

## OpenAI Responses API

*需要 0.31.0 及以上版本。*

```ts
import { createBareAgent, createOpenAIResponsesClient } from "agent-lattice";

const agent = createBareAgent({
  model: process.env.OPENAI_MODEL ?? "gpt-4.1",
  maxTokens: 4096,
  requestTimeoutMs: 60_000,
  modelClient: createOpenAIResponsesClient({
    apiKey: process.env.OPENAI_API_KEY,
  }),
});

const result = await agent.prompt("Say hello");
console.log(result.result);
```

工厂默认读取 `OPENAI_API_KEY`，基础地址默认为 `https://api.openai.com/v1`。
凭据和自定义 `baseURL` 应传给工厂，而不是智能体。显式 `modelClient`
会替换默认 Anthropic 客户端；智能体上的 `apiKey`/`baseURL` 不会配置这个注入的客户端。

### 通过 Responses 使用 DeepSeek

*需要 0.32.0 及以上版本。*

```ts
import { createBareAgent, createOpenAIResponsesClient } from "agent-lattice";

const responsesAgent = createBareAgent({
  model: "deepseek-flash",
  maxTokens: 4096,
  requestTimeoutMs: 60_000,
  modelClient: createOpenAIResponsesClient({
    apiKey: process.env.DEEPSEEK_API_KEY,
    baseURL: "https://api.deepseek.com",
    reasoningEffort: "low",
  }),
});

const result = await responsesAgent.prompt("What is 2 + 2?");
console.log(result.result);
```

每次查询可用 `thinkingConfig: { type: "disabled" }` 关闭思考；官方 DeepSeek
端点的 `enabled` 和 `adaptive` 会开启思考。DeepSeek 忽略思考 token 预算。
智能体/查询的 `reasoningEffort` 覆盖工厂力度，`max` 原样发送为 `max`。
其他 Responses provider 仍需遵守各自支持的力度范围，省略时使用 provider 默认值。
强制补交恢复和推理历史要求见
[Provider 兼容性](/zh/reference/provider-compatibility/#deepseek-responses-api)。

### 输出上限与非流式调用

`maxTokens` 属于智能体，会映射为 Responses 的 `max_output_tokens`。
使用注入客户端、且智能体未设置 DeepSeek `baseURL` 时，正常默认值为 16384；
客户端工厂不会改变该上限。需要控制延迟和输出成本时，请显式设置预算。
Anthropic 兼容请求若使用 DeepSeek 的大默认预算，底层 Anthropic 客户端可能要求
流式调用，除非设置合适的 `maxTokens` 或显式请求超时。示例在两种协议下均设置
明确的预算和超时。

## 系统提示词

使用 `systemPrompt` 定义 agent 的稳定角色、职责和边界。团队场景尤其需要它，因为每个真正工作的 `Agent` 都应该有自己的职责描述。

```ts
const backendAgent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-flash",
  systemPrompt: [
    "你是 backend 执行 agent。",
    "你负责 API、数据模型、存储、集成和服务端正确性。",
    "遇到产品或 UI 决策时向上级反馈，不要擅自假设。",
  ].join("\n"),
});
```

## Workspace

每个 agent 默认都有自己的私有 workspace，用于存储持久化文件、代码、报告、日志和测试证据。workspace 属于这个 agent，不属于 `Team` 或 `teamMember()` 定义。

默认路径是 `~/.agent/workspaces/<agent-name>`。如果 agent 没有 `name`，则使用 `~/.agent/workspaces/agent-<session-id>`。

```ts
const backendAgent = createAgent({
  apiKey,
  name: "backend",
  model,
  systemPrompt: "你是 backend 执行 agent。",
});
```

只有当宿主想覆盖默认位置时，才需要显式传入 `workspace`：

```ts
const backendAgent = createAgent({
  apiKey,
  name: "backend",
  model,
  workspace: ".agent-workspaces/backend",
});
```

SDK 会自动给 agent 增加 workspace 工具，并注入说明：交付时用自然语言汇报重要路径和验证结果。

传 `workspace: false` 可以完全关闭内建工作区：不装内建文件/Shell 工具，也不加 workspace 提示段落——等价于 `createBareAgent()`。*需要 0.23.0 及以上版本。* 与 `createBareAgent()` 不同，这个选项对 `defineAgent()` 也生效，`defineAgent({ workspace: false })` spawn 出来的就是裸会话。适合不需要任何文件系统和 Shell 权限面的 typed 委派专科子 agent。

## Bare agent

当宿主需要一个不带默认提示词、不带默认工具、也不创建 workspace 目录的纯模型循环时，使用 `createBareAgent()`。它适合已经由宿主提供 sandbox 的应用、需要精确控制工具列表的测试，或由应用自己组装能力的 wrapper。

```ts
import { createBareAgent, createBuiltinTools } from "agent-lattice";

const agent = createBareAgent({
  apiKey,
  model,
  systemPrompt: "你是一个简洁的工程助手。",
  tools: createBuiltinTools({
    cwd: process.cwd(),
    allowedDirectories: [process.cwd()],
  }),
});
```

大多数需要产出持久文件的 agent 应该使用 `createAgent()`。只有当应用要显式拥有每一项能力时，才选择 `createBareAgent()`。

## 中断请求

`AbortSignal` 会中断当前模型请求和后续工具循环：

```ts
const controller = new AbortController();

setTimeout(() => controller.abort(), 5000);

const result = await agent.prompt("总结这个仓库。", {
  signal: controller.signal,
});
```

## Query options

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `stream` | `boolean` | `true` | 是否启用模型流式调用，并输出 `stream_event` 事件。 |
| `signal` | `AbortSignal` | `undefined` | 取消当前模型请求和工具循环。 |

## 轮次限制

`maxTurns` 统计的是模型请求次数，不是工具执行次数。默认值是 `50`，这样多智能体和重工具调用流程有足够空间完成，同时仍然能防止无限循环。

小型一次性工具或测试场景可以显式调低：

```ts
const agent = createAgent({
  apiKey,
  model,
  maxTurns: 8,
});
```
