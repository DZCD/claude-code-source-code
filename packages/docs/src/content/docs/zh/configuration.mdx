## DeepSeek

DeepSeek 提供 Anthropic 兼容接口，所以只需要配置 `baseURL` 并使用 DeepSeek 模型名。

```ts
import { createAgent } from "claude-team-agent-sdk";

const agent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-v4-flash",
  systemPrompt: "你是一个简洁的工程助手。",
  maxTokens: 16384,
  maxTurns: 50,
});
```

## Anthropic

直接使用 Anthropic 时可以省略 `baseURL`：

```ts
const agent = createAgent({
  apiKey: process.env.ANTHROPIC_API_KEY,
  model: "claude-sonnet-4-6",
  systemPrompt: "你是一个简洁的工程助手。",
});
```

## 系统提示词

使用 `systemPrompt` 定义 agent 的稳定角色、职责和边界。团队场景尤其需要它，因为每个真正工作的 `Agent` 都应该有自己的职责描述。

```ts
const backendAgent = createAgent({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com/anthropic",
  model: "deepseek-v4-flash",
  systemPrompt: [
    "你是 backend 执行 agent。",
    "你负责 API、数据模型、存储、集成和服务端正确性。",
    "遇到产品或 UI 决策时向上级反馈，不要擅自假设。",
  ].join("\n"),
});
```

## Workspace

每个 agent 默认都有自己的私有 workspace，用于存储持久化文件、代码、报告、日志和测试证据。workspace 属于这个 agent，不属于 `Team` 或 `teamMember()` 定义。

默认路径是 `~/.agent/workspaces/<agent-name>`。如果 agent 没有 `name`，则使用 `~/.agent/workspaces/agent-<session-id>`。

```ts
const backendAgent = createAgent({
  apiKey,
  name: "backend",
  model,
  systemPrompt: "你是 backend 执行 agent。",
});
```

只有当宿主想覆盖默认位置时，才需要显式传入 `workspace`：

```ts
const backendAgent = createAgent({
  apiKey,
  name: "backend",
  model,
  workspace: ".agent-workspaces/backend",
});
```

SDK 会自动给 agent 增加 workspace 工具，并注入说明：交付时用自然语言汇报重要路径和验证结果。

## 中断请求

`AbortSignal` 会中断当前模型请求和后续工具循环：

```ts
const controller = new AbortController();

setTimeout(() => controller.abort(), 5000);

const result = await agent.prompt("总结这个仓库。", {
  signal: controller.signal,
});
```

## Query options

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `stream` | `boolean` | `true` | 是否启用模型流式调用，并输出 `stream_event` 事件。 |
| `signal` | `AbortSignal` | `undefined` | 取消当前模型请求和工具循环。 |

## 轮次限制

`maxTurns` 统计的是模型请求次数，不是工具执行次数。默认值是 `50`，这样多智能体和重工具调用流程有足够空间完成，同时仍然能防止无限循环。

小型一次性工具或测试场景可以显式调低：

```ts
const agent = createAgent({
  apiKey,
  model,
  maxTurns: 8,
});
```
