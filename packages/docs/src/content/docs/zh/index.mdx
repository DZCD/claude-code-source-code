## 这个 SDK 解决什么

Claude Agent SDK 是一个轻量 npm 包，用来在你自己的 Node.js 应用里构建 Claude 风格的 Agent，而不需要安装或嵌入 Claude Code CLI。

它适合这些场景：

- 你想把 agent loop 集成进自己的服务端、桌面端或 Worker runtime。
- 你需要自定义工具、权限审批、流式事件，而不是完整的 Claude Code UI。
- 你希望支持 Anthropic 兼容接口，比如 DeepSeek 的 Anthropic-compatible endpoint。
- 你想要可组合的 MCP、skills、内置文件工具、sub-agent 或团队 mailbox 协作能力。

## 能力概览

  <Card title="Agent 循环" icon="setting">

  <Card title="自定义工具" icon="puzzle">

  <Card title="权限回调" icon="lock">

  </Card>
  <Card title="稳定事件" icon="seti:json">

## 安装

```bash
npm install claude-team-agent-sdk zod
```

这个包刻意和 Claude Code 解耦。它不依赖 Claude Code CLI、Ink UI、AppState、sessionStorage 或 Claude Code 的内部运行时。
