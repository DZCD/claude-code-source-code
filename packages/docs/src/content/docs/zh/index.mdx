## AgentLattice 解决什么

AgentLattice 是一个智能体解决方案开发框架，用来在你自己的 Node.js 应用里构建协作式智能体系统，而不需要安装或嵌入 Claude Code CLI。

它适合这些场景：

- 你想把 agent loop 集成进自己的服务端、桌面端或 Worker runtime。
- 你需要自定义工具、权限审批、流式事件，而不是完整的 Claude Code UI。
- 你希望支持 Anthropic 兼容接口，比如 DeepSeek 的 Anthropic-compatible endpoint。
- 你想要可组合的 MCP、skills、内置文件工具、AgentLike 委托或团队 mailbox 协作能力。

## 能力概览

<CardGrid>
  <Card title="Agent 循环" icon="setting">
    保存对话状态，调用 Anthropic 兼容模型，识别工具调用，执行工具，再把结果回填给模型。
  </Card>
  <Card title="自定义工具" icon="puzzle">
    用 Zod schema 定义输入，SDK 会解析参数并转成模型可用的 JSON Schema。
  </Card>
  <Card title="权限回调" icon="lock">
    在工具真正执行前由宿主应用决定允许或拒绝，适合文件、Shell、远程操作等敏感能力。
  </Card>
  <Card title="稳定事件" icon="seti:json">
    通过 `system`、`assistant`、`user`、`stream_event`、`result` 事件消费运行过程。
  </Card>
  <Card title="Supervisor 委派" icon="add-document">
    当主智能体需要临时专家时，把另一个 `AgentLike` 包装成模型可调用工具。
  </Card>
  <Card title="Mailbox 团队" icon="document">
    用持久 work item、回复、状态和 runtime-driven handoff 协调命名成员。
  </Card>
</CardGrid>

## 安装

```bash
npm install agent-lattice zod
```

AgentLattice 的 npm 包名是 `agent-lattice`，并且刻意和 Claude Code 解耦：它不依赖 Claude Code CLI、Ink UI、AppState、sessionStorage 或 Claude Code 的内部运行时。
